# Motorola Hardware Interfaces & MotoActions

Hardware Abstraction Layers (HALs), sepolicy, and MotoActions for Motorola devices on LineageOS / Android 16 (`lineage-23.2`).

## Contents

* **MotoActions:** Actions, gestures, and sensor-based utilities (Chop-Chop for flashlight, Flip-to-Mute, Lift-to-Silence, Proximity Silencer, Doze Pulse).
* **HIDL / AIDL HALs:** Motorola-specific hardware services, touch, power, and sensors.
* **Sepolicy:** SELinux policies for Motorola hardware interfaces.
